# Security Policy

## Supported Versions

The latest release and main branch receive maintenance and security updates:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security concern, sensitive data disclosure, or vulnerability within this repository, please report it privately:

1. Open a confidential report via GitHub Security Advisories or contact the repository owner at their GitHub profile.
2. Include reproduction steps, environment details, and affected components.
3. We will review and address valid reports promptly.
